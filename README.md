# TypeScript Learning 🚀

This repository contains my **TypeScript learning journey**, from the fundamentals to deeper concepts about how TypeScript works internally.

The goal is not just to write TypeScript code, but to understand the **core ideas, type system, compiler, and development workflow** behind TypeScript.

## 📚 What You'll Find

* TypeScript fundamentals and core concepts
* Type inference and type annotations
* Type system and common types
* TypeScript compiler and compilation pipeline
* Parser, AST, Binder, Type Checker and Emitter
* Practical TypeScript examples and experiments
* Notes and explanations for the topics I learn

## 📁 Repository Structure

```text
typescript-learning/
│
├── src/                  # TypeScript source code
├── dist/                 # JavaScript generated from TypeScript
├── topics/               # Learning notes and topic READMEs
└── README.md             # Repository overview
```

### `src/`

Contains the TypeScript code I write while learning and experimenting.

### `dist/`

Contains the JavaScript output generated from the TypeScript source.

### `topics/`

Contains my notes and READMEs for the concepts I learn.
